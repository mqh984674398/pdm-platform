## 建议分期

- **P1 决策引擎(后端,可独立验收)**:统一证据对象+§4.3 优先级+§4.4 三态,安全规则不可评估时输出"安全监测降级"并进入告警/展示;测试覆盖三态。不改界面结构。
- **P2 配置版本与发布**:预测配置版本模型(不可变)、编译器、校验流水线(数据校验/编译/历史回放/仿真)、激活;数据源管理(涛思连接+测试)。
- **P3 算法链路与模板**:部件类型扩展、算法目录与输入契约、自动匹配与输入校验、T²/马氏距离、插件接口、关系类型。
- **P4 工作台界面**:单页工作台、树 CRUD 抽屉、七步向导、状态展示配置、zh/en、e2e。

P1 价值最高且决定安全语义,先做;P4 依赖 P2/P3 的 API,放最后。
