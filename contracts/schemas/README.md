# Contract schemas

- Source of truth: Pydantic models in `backend/app/*/schemas.py` (one module per layer, ARCHITECTURE §3).
- `openapi.json` is generated by `backend/scripts/export_openapi.py` and includes every contract model, endpoint-backed or not (`backend/app/api/contracts.py`).
- Frontend types: `frontend/src/api/generated.ts` via `npm run gen:types`; readable aliases in `frontend/src/api/contracts.ts`.
- `tools/check_schema_drift.sh` fails when either generated file is stale (runs in CI).

Key rules encoded in the schemas:

| Rule | Where |
|---|---|
| Result provenance (GEN-06) | `ResultMeta` required on all prediction results, baselines, evidence, decisions |
| Simulated labeling (GEN-03) | required `is_simulated` on every data-carrying model |
| Typed outputs (L5-06) | `PredictionResult` discriminated by `kind`; failure probability needs failure evidence |
| Explicit abstention (GEN-07) | `UnsupportedPrediction` is a member of `PredictionResult` |
| Healthy reference protection (L4-06) | `VERIFIED_HEALTHY` baselines require `verified_by` and `verified_at` |
| Replacement lifecycle (L3-06) | `REPLACEMENT` events must name `new_lifecycle_id` |
| Maintenance workflow (L3-07) | `WORKFLOW_TRANSITIONS` / `can_transition` |
| No credentials in API (SEC-03) | `DataSourceConfig.credential_ref` only |
| Timezone-aware timestamps | all timestamps are `AwareDatetime` |
