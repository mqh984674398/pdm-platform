# Fixtures (SIMULATED)

Small excerpts of scenario files for fast unit tests, regenerated by `python -m app.simulation.scenarios`.

- `S01_ball_screw_normalized.csv`, `S14_linear_motor_raw.csv`, `S18_cylinder_raw.csv`: scenario excerpts for unit tests.
- `demo_fleet.json`: eight demo machines for the dashboard (T007). Health is each scenario's expected Golden Case result, not a computed value; the file says so in `health_basis`.
- `studio_demo.json`: the simulated "telemetry" source behind the Data Source Studio mock (T008), with preview windows chosen to contain the S13, S14, and S16 data faults.
