# Fixtures (SIMULATED)

Small excerpts of scenario files for fast unit tests, regenerated by `python -m app.simulation.scenarios`.

- `S01_ball_screw_normalized.csv`, `S14_linear_motor_raw.csv`, `S18_cylinder_raw.csv`: scenario excerpts for unit tests.
- `demo_fleet.json`: eight demo machines for the dashboard (T007). Health is each scenario's expected Golden Case result, not a computed value; the file says so in `health_basis`.
- `studio_sources.json`: backend configuration of the simulated source `sim-iot` (S01, S13, S14, S16 as one source) used by the Data Source Studio API (T011), `backend/scripts/demo_server.py`, and the end-to-end tests. Preview windows are chosen to contain the S13, S14, and S16 data faults.
- `studio_demo.json`: the same source as a static snapshot for the frontend's offline mock (unit tests and the G1 demo build with `VITE_STUDIO_API=mock`).
